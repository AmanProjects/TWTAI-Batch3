Two ways to take part

A writers' track and an engineering track

Every module works for non-coders. Days 7 and 8 split into parallel tracks so the writers' path never asks you to write HTML, TypeScript, or a language server—you direct the AI and review its work instead.

Writers' track · primary

Direct and review

You describe what you want in plain language, upload your own docs, and review what the AI produces the way you would edit a colleague's draft. This is the recommended path for most participants.

Engineering track · optional depth

Build and extend

You read and write the underlying code—TypeScript MCP servers, language servers, and plugin manifests—for the full end-to-end build. Choose this if you manage docs-as-code pipelines.

Choose your tool

Claude Code or the Claude.ai web interface

The course was written around Claude Code, the command-line tool. Most of the writing and review work in days 1 through 5 can be done entirely in the Claude.ai web interface instead—through Projects, custom Skills, and Connectors. Every workshop page flags the web alternative to each command-line step, and the dedicated guide maps the two side by side.
