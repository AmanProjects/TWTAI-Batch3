Day 4—Sharing your skills: marketplaces and plugins

Intermediate Module 4 2 hours Paired workshop Claude Code
Full lesson

This page is the workshop summary and agenda. For the complete lesson text, open the Module 4 lesson.

Overview

From a skill you use to a skill your team uses

A skill that only you can run helps one person. Day 4 is about distribution: the marketplace → plugin → component hierarchy, the difference between a command, a skill, an agent, a hook, and an MCP server, and the hands-on loop of bundling your skills into a plugin and publishing a marketplace a teammate can install from.

Mostly Claude Code today

Plugins and marketplaces are a Claude Code feature. There is no browser equivalent for publishing a marketplace yet. Writers staying on the web can still share—see the web alternatives below for how to distribute skills without plugins.

Learning objectives

By the end of this day you can

  • Explain the marketplace → plugin → component hierarchy in plain language.
  • Tell the difference between a command, a skill, an agent, a hook, and an MCP server inside a plugin.
  • Install a marketplace and a plugin as an individual.
  • Bundle your own skills into a plugin and publish a marketplace on GitHub.
  • Help a teammate add your marketplace and run your skills.

The hierarchy

Four nouns, nested

NounWhat it is
MarketplaceA GitHub repo that lists one or more plugins people can add.
PluginAn installable bundle of components with a manifest.
ComponentA command, skill, agent, hook, or MCP server inside the plugin.
Component typesEach does one job; day 8 covers all of them end to end.

Workshop

Publish and install, paired

  1. Install the live example

    Add the example marketplace, then install its doc-skills plugin, to see the install experience from the user's side first.

  2. Bundle your skills

    Collect the skills you built in day 3 into a plugin with a manifest.

  3. Publish to GitHub

    Push the marketplace repo so it has a public address.

  4. Have your partner install it

    Your partner adds your marketplace and runs your skills cold—the real test.

Doing it on the web

Claude.ai web alternatives

Claude Code (as written)

Add a marketplace with /plugin marketplace add and install with /plugin install doc-skills@twtai. Publishing means pushing a marketplace repo to GitHub.

Claude.ai web interface

There is no marketplace install in the browser. To share a web Skill, export its SKILL.md and send it; your teammate adds it under Customize → Skills → Upload. For whole teams, a Team or Enterprise admin provisions org Skills centrally so everyone gets them automatically.

The underlying idea is shared either way

A marketplace is "one place my team installs from." On the web, org-provisioned Skills play that role: the admin is the marketplace. The plugin mechanics are Claude Code; the distribution goal is the same.

Homework

Before day 5

  • Publish your own plugin or marketplace and get one teammate running it.
  • Bring one skill you would like a second writer to review in day 5.

Checklist

Intermediate checklist

  • Someone other than me has installed and run my skill.
  • I can name all four component types.
  • I know when a plugin is overkill versus worth it.
