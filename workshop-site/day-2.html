Overview

The vocabulary that unlocks everything after it

Day 2 introduces the Model Context Protocol—the open standard that lets AI connect to tools and data—and the idea of an Agent Skill, which is the single most useful thing a technical writer can build. You will leave able to look at your own workflow and spot which tasks should become skills and which need tools.

Concepts today, building later

This day is about understanding, not installation. It works fully in the Claude.ai web interface. The place MCP shows up in the browser is Connectors—covered in the web guide.

Learning objectives

By the end of this day you can

  • Explain MCP in plain language using the USB analogy.
  • Distinguish between tools, resources, and prompts in MCP.
  • Explain what an Agent Skill is and why technical writers are natural skill creators.
  • Identify three tasks in your own workflow that could become skills or tools.

Activity

Skill or tool identifier worksheet

Classify eight documentation tasks as skill, tool, both, or neither, then pick the one that would make the best first skill to build.

If the task is...It is probably a...
A repeatable judgement you make with instructions in your headSkill
A connection to live data or an external system (a tracker, a repo, an API)Tool
A judgement that also needs live data to do its jobBoth
A one-off that you will never repeatNeither

Doing it on the web

Claude.ai web alternatives

Claude Code (as written)

Skills live as .claude/commands/*.md files in your project or ~/.claude/skills/. MCP servers are added with claude mcp add.

Claude.ai web interface

A skill becomes a custom Skill created under Customize → Skills, or a Project's custom instructions. An MCP server becomes a Connector you enable in settings. Same three parts—tools, resources, prompts—surfaced through the browser instead of a config file.

Keep this straight

"Where skills live" differs by tool, but what a skill is—a reusable instruction set Claude can load on demand—is identical everywhere. The day-3 build teaches the concept; the web guide shows where to click.

Homework

Before day 3

  • Choose the one task from your worksheet that will become your first skill.
  • Write, in two or three sentences, exactly what a good output for that task looks like.

Checklist

Novice checklist

  • I can explain MCP with the USB analogy.
  • I can tell a skill from a tool.
  • I have chosen my first skill to build.
