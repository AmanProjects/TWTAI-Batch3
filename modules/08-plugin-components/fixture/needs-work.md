# Getting Started With The Orders API

## Overview

In order to be able to successfully begin working with the Orders API, it is
necessary for the user to first obtain an API token, which can be generated by
navigating to the Settings page of the developer console and then clicking on
the button that is labelled "Create Token".

Simply paste the token into your client and you are done.

## Authentication

All requests must be authenticated. The token should be sent in the
Authorization header.

## Next Steps

Obviously you will want to read the reference documentation, which is
comprehensive and covers every single endpoint that is exposed by the service
including the ones that are deprecated but still supported for the time being.
