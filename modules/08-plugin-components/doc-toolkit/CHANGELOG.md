# Changelog

All notable changes to `doc-toolkit`.

## [1.0.0] — 2026-08-07

### Added

- `readability-pass` skill with an on-demand `reference.md`
- `/doc-toolkit:doc-status` command
- `doc-auditor` read-only subagent
- SessionStart, PostToolUse, PreToolUse, and Stop hooks
- `docstats` bundled stdio MCP server and a remote HTTP server entry
- `markdown-docs` LSP server publishing long-sentence diagnostics
- `docs-build` and `audit-log` monitors
- `Docs Dark` theme and `terse-editor` output style
- `docs-sweep` workflow
- `doc-wordcount` executable on PATH
