The RTCCO Framework

ElementWhat It Does
RoleSets the AI's perspective and expertise
TaskWhat the AI should do

Most beginners include Role and Task. The differentiator is Context, Constraints, and Output.

Prompt Quality Comparison

Weak (no RTCCO):

Review this file.

Partial (Role + Task only):

You are a technical editor.
Review this API doc for completeness.

Strong (full RTCCO):

You are a senior technical editor with 10 years in API documentation.
Review the API endpoint doc at $ARGUMENTS for completeness.
Context: Readers are junior developers. We follow Google Dev Style Guide.
Constraints: Do NOT modify code. Flag issues in prose only.
Output: Markdown table — Section | Status | Finding | Fix

What Are Agent Skills?

Skills are reusable prompt templates — saved expert personas you invoke with /skill-name.

  1. Create a markdown file (SKILL.md or .claude/commands/*.md)
  2. When invoked, content is injected as instructions
  3. Claude executes using built-in tools (read, search, bash)

Skills do not run code themselves — they guide AI behavior.

Use skills for AI judgment. Use MCP tools for deterministic logic.

Skill Anatomy (RTCCO in Practice)

You are a [ROLE].                         ← R
Review the file at: $ARGUMENTS            ← T + input
Context: [audience, style guide]          ← C
Check for: 1. … 2. …                      ← detailed task
Constraints: [what NOT to do]             ← C
Output: [exact table or list format]      ← O

Templates: resources/skill-templates.md · Examples: sample-project/.claude/commands/

The $ARGUMENTS Variable

Review the documentation at: $ARGUMENTS

When you run:

/check-api-doc path/to/my-api.md

$ARGUMENTS becomes path/to/my-api.md

This is what makes a skill reusable — it works on any file.

Level Up: The skill-creator Tool

You built a skill by hand. Now automate the busywork.

skill-creator interviews you, scaffolds Format B skills, and can test and improve existing ones.

Install (one time):

/plugin install skill-creator@claude-plugins-official

Use it: /skill-creator — then describe your task in plain language.

RTCCO is the recipe. skill-creator is the sous-chef.
