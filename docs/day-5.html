Do this before the session — Confluence and Jira

Module 5 connects Claude to a live Atlassian site. Create your free Confluence and Jira site and connect the Atlassian MCP server beforehand. Step-by-step: setup guide → Atlassian prerequisites. Use a throwaway personal account, never a work account.

Overview

Connect to real data and work as a team

Day 5 adds two capabilities. First, connecting standard MCP servers—Git, Atlassian, and Microsoft Learn—so skills can reach live data. Second, the team practices that make a skill library durable: structured peer review, multi-step skill composition, and maintenance rules that keep a shared library from rotting.

Learning objectives

By the end of this day you can

  • Compose multiple skills into a coordinated multi-step workflow.
  • Explain what MCP servers are and why they matter for documentation automation.
  • Configure standard MCP servers—Git, Atlassian, Microsoft Learn.
  • Conduct a structured peer review of another writer's skill.
  • Design a team skill library that multiple people can use and maintain.
  • Identify the boundary between what skills can do and what requires an MCP tool.

Peer review

Score with the shared rubric

In groups of three, review each other's skills against seven criteria—clarity, role definition, checklist or rules, output format, boundaries, flexibility, and testability—on a one-to-three scale. A skill scoring 15 of 21 or higher is considered team-ready.

The full rubric lives in resources/peer-review-rubric.md.

Doing it on the web

Claude.ai web alternatives

Claude Code (as written)

Add servers with claude mcp add—Git locally, Atlassian over remote HTTP, Microsoft Learn via a plugin. There is no GUI settings panel in Claude Code.

Claude.ai web interface

MCP servers appear as Connectors. Enable remote connectors (such as Atlassian) in settings in the browser; local servers like Git run through Claude Desktop instead. Remote connectors are available across plans, with Free limited to one custom connector.

Where the web stops

Connecting ready-made servers works on the web. Running a local server you built yourself needs Claude Desktop or Claude Code—that is the subject of day 6.

Homework

Before day 6

  • Apply your peer reviewers' feedback and re-score your skill.
  • Compose a two-step workflow from two of your skills and run it end to end.

Checklist

Intermediate checklist

  • I connected at least one MCP server or Connector and used it in a skill.
  • I gave and received a structured peer review.
  • I can describe the structure of a maintainable team skill library.
