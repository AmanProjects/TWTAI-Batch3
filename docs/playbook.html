Two paths, one goal

Browser or command line

If you work in the browser

  • Build skills under Customize → Skills.
  • Keep your style guide and examples in a Project.
  • Connect live systems as Connectors.
  • Publish your day-7 site through GitHub Pages in the browser.

Full web guide →

If you work in Claude Code

  • Save skills as .claude/commands/*.md.
  • Add servers with claude mcp add.
  • Bundle and ship with /plugin and marketplaces.
  • Capture conventions in a CLAUDE.md.

See resources/cheat-sheet.md.

Make it stick

Your 30-day adoption plan

  1. Week 1—pick one task

    Choose the single documentation task you repeat most. Build one skill for it and use it every day this week.

  2. Week 2—add your context

    Put your real style guide and a known-good example into a Project or as a resource, so the skill reflects your house standard.

  3. Week 3—share one thing

    Hand one skill to one teammate and watch them run it cold. Fix whatever confused them.

  4. Week 4—write it down

    Draft your personal AI integration plan: which tasks are automated, which stay manual, and what you will tackle next quarter.

Keep it healthy

Skill maintenance habits

  • Review each shared skill monthly; delete any no one runs.
  • Keep a known-good and a known-bad test document for every skill, and re-run both after any change.
  • Treat a skill like docs: give it an owner, a changelog, and a clear description.
  • Remember the token budget—every component a plugin carries is loaded in every conversation, so keep bundles lean.

When something breaks

Quick troubleshooting

SymptomTry this
The skill gives different answers each runTighten the constraints and output format; add a worked example.
Claude ignores the skill in the browserSharpen the Skill description so it clearly matches the request; confirm custom Skills are enabled on your plan.
A Connector will not appearCheck the plan limit—Free allows one custom connector—and whether a local server needs Claude Desktop.
claude: command not foundReopen the terminal; the npm global bin folder may not be on your PATH. See the setup guide.
A teammate cannot install your pluginHave them test cold on their own machine; confirm the marketplace repo is public and the manifest validates.
