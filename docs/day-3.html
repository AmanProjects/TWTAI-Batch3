This page is the workshop summary and agenda. For the complete lesson text, open the Module 3 lesson and the hands-on workshop.

Overview

Turn a good prompt into a reusable skill

Day 3 is where you stop prompting ad hoc and start building. You will learn the five elements of an effective prompt through the RTCCO framework, then package that prompt into a working skill you can run again and again—your first /check-api-doc—and iterate on it until the output is consistent.

Learning objectives

By the end of this day you can

  • Name the five elements of an effective prompt and apply each one.
  • Explain where skills live and how scope—project, personal, global—affects sharing.
  • Create a working skill from scratch using the RTCCO framework.
  • Test and iterate on a skill until it produces consistent, useful output.
  • Use skill-creator to scaffold or refine a skill.

The framework

RTCCO—five elements of a strong prompt

LetterElementIn a documentation skill
RRole"You are a senior API documentation editor."
TTask"Review this document against the six required sections."
CContext"Our audience is third-party developers integrating our REST API."
CConstraints"Only flag what is missing or incomplete. Do not rewrite."
OOutput format"Return a table: section, status, finding, fix."

Workshop

Build /check-api-doc

  1. Draft the prompt with RTCCO

    Write out all five elements for an API-doc completeness reviewer.

  2. Save it as a skill

    Store the prompt where Claude can load it on demand and invoke it by name.

  3. Test against a known-bad document

    Run it on sample-project/test-docs/bad-api-doc.md and check whether every gap is caught.

  4. Iterate

    Tighten constraints and output format until two runs on the same input agree.

Doing it on the web

Claude.ai web alternatives

This is the first day where the "where skills live" difference matters, so here is the full mapping.

Claude Code (as written)

Create .claude/commands/check-api-doc.md containing the RTCCO prompt, then invoke it with /check-api-doc. Install the scaffolder with /plugin install skill-creator@claude-plugins-official.

Claude.ai web interface

Go to Customize → Skills → Add. Either paste the instructions, upload a SKILL.md, or choose Create with Claude and describe the task—Claude writes the skill for you. Claude then loads it automatically when relevant, or you can name it. Custom Skills need code execution and file creation enabled, on Pro, Max, Team, or Enterprise.

Scope still matters on the web

Personal Skills are yours; organization Skills are provisioned by a Team or Enterprise admin for everyone. The project / personal / global idea maps onto Project knowledge, your personal Skills, and org-provisioned Skills respectively.

Homework

Before day 4

  • Build a second skill for one of the other repeated tasks from your worksheet.
  • Run both skills on real work and note where they still need tightening.

Checklist

Beginner checklist

  • I have a working skill that produces consistent output.
  • I can explain each letter of RTCCO.
  • I know where my skills live and who can see them.
