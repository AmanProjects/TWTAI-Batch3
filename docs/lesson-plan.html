Facilitator lesson plan

8 modules 16 hours live Two tracks Novice → expert

How to use this

One plan, two tracks, eight sessions

Each module is a two-hour live session. This plan gives facilitators the objectives, the activity, the tool decision, and the time split at a glance. Lead with the writers' (web) path and offer the engineering (Claude Code) path as optional depth. The per-day pages carry the detailed agendas.

Before the first session

Confirm every participant has a working environment. Web-track participants need a Claude account with custom Skills enabled; engineering-track participants complete the full setup guide. Do not start module 1 with an unresolved setup in the room.

Standard shape

The rhythm of every session

  • First 10–15 min
    Recap and homework share
    Surface what participants tried since last time. This is where retention happens.
  • Next 25–35 min
    Concept
    One analogy, one framework. Keep it concrete and tied to documentation work.
  • Middle 35–40 min
    Hands-on activity
    The heart of the session. Every participant produces something.
  • Final 15–20 min
    Discussion, takeaway, homework
    Reflection questions, one key idea, and a small task that feeds the next day.

Facilitation notes

What to watch for

Days 1–3 · build confidence

These are web-friendly and low-risk. The goal is that every participant completes a real task and keeps a reusable prompt or skill. Do not let tooling debates stall the room—point web users to Customize → Skills and move on.

Days 4–6 · the tooling split widens

Here the paths diverge. Pair web-only participants with a Claude Code user for the plugin and server exercises, or route them to the no-code understanding path. Flag clearly, each time, which steps are command-line only.

Day 7 · let the capstone breathe

The publish step is where people get stuck. The browser-only GitHub Pages route works for everyone and needs no terminal—default to it unless a participant specifically wants the Git route.

Day 8 · depth over coverage

Thirteen components is a lot. For the writers' track, three well-understood pieces beat a tour of all thirteen. Keep hammering the token-budget point.
